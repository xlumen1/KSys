# KSys
*Ok Operating System*

## Overview
**KSys** is the spiritual successor to [LumenOS](https://github.com/xlumen1/LumenOS).
Due to scope creep, various bugs, and a terrible codebase, LumenOS' development has been put on indefinate hold.
Instead, KSys will be developed in its place.

## Dependencies

### Build Dependencies
- `clang`
- `lld`
- `llvm`
- `make`

### Test Dependencies
- `qemu`
- `make`
- `gdb`
- `ovmf`

## Contributing
Contributions are welcome!
Feel free to fork this repository, open issues, or submit pull requests.
However, there is a work in progress specification on how KSys should function, so until that is published, it is unlikely that major feature pull requests will be merged.
